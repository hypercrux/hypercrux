# F1: Codec

Status: next, in one round with P4 and S1. Planned at 2 hours. It needs P2
and P3, which are done.

## The contract

From BETA.md: the codec, batches, markers and headers encoded as pure
functions. Done when the golden fixtures match byte for byte, random round
trips pass, and a 30-minute fuzz of the decoder runs clean.

## What's there already

- **The format,** `beta/FORMAT.md`: the header, batches, markers, the six
  changes and the six kinds of value, and what makes a batch count.
- **The fixtures,** in `beta/internal/format/testdata`, and
  `fixtures_test.go`, which reads them with a small reader written from the
  spec alone. The codec has to give the fixtures' bytes exactly.
- **The types** (P3): `format.Change` and `format.Field`, and
  `value.Value`. The codec turns a `[]format.Change` into a batch and back.

## To settle, and write down in this file

- **The functions:** encoding and decoding a header, a batch and a marker,
  each pure, with no file in sight. Decoding a batch keeps FORMAT.md's line
  between a batch that counts (its own five checks) and changes that are
  malformed, which is damage, so the log can tell them apart.
- **What the decoder checks:** the syntax and the rules for names, kinds,
  lengths and values. The checks against the state, such as a put into a
  table that exists, are the store's.
- **Memory:** a batch decoded from one buffer, slicing text, bytes and
  vectors out of it, with what the store must copy.
- **The tests:**
  - every fixture encoded and decoded byte for byte;
  - random round trips, encode(decode(b)) == b, with awkward values;
  - fuzz targets on the decoders, which the CI fuzz job picks up by itself.
- **The 30-minute fuzz** of the decoder. Run it once the round's other
  agents have finished, since they share this two-core machine; the
  coordinator can run it after merging.
