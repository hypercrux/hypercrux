# F2: Log and write lock

Status: next, in one round with S2 and T1. Planned at 3 hours. It needs F1,
which is done.

## The contract

From BETA.md: the log and the write lock: create, append, sync, marker,
reading on open; the mutex then `flock` with the 10-second wait; the device
and inode check. Done when batches survive a reopen, the lock times out
across processes, and a replaced file restarts the commit.

## What's there already

- **The format and its rules,** in `beta/FORMAT.md`: "Writing", "Creating a
  database", "Reading the log" and "Checking the end of the log".
- **The codec** (F1): `AppendHeader`, `DecodeHeader`, `AppendBatch`,
  `DecodeBatch`, `BatchLength`, `AppendMarker` and `DecodeMarker` in
  `beta/internal/format`. F1.md's notes under F2 say how opening and a
  commit use them.
- **The file calls** (P3): `fsys.File` and `fsys.FS`, still without a real
  implementation. P3.md's notes under F2 list what the real one needs:
  O_CLOEXEC, fdatasync, fchmod after create, EINTR, and `renameat2` with
  numbers `syscall` lacks on amd64.
- **The package map** (P3): the log lives in `beta/internal/logfile`.

## To settle, and write down in this file

- **The real file calls,** `fsys.OS` or the like, over `syscall`.
- **The log's API:** create a database by FORMAT.md's procedure, open one
  and read every marked batch through a callback that takes a change list,
  append a batch with its sync and marker, and close.
- **The lock:** a mutex inside the process, then `flock`, waiting up to 10
  seconds in all, released in the reverse order; once held, the device and
  inode check, and a restart on the new file when the path names another.
- **What waits for later tasks:** the tail check and its repairs are F3's,
  damage F4's, failed commits F5's, following other processes F6's and the
  file rules F7's. F2 stops at the end of the log and leaves a clear place
  for each.
- **The tests:** batches surviving a reopen; the lock timing out across two
  processes; a file replaced under a writer making it restart its commit.
