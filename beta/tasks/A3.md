# A3: Differential harness

Status: next. Planned at 3 hours. It needs A1, which is done.

## The contract

From BETA.md: random sequences of operations run on two engines and
compared, with distances within the stated bound and failing sequences kept.
Done when 0.x against itself passes, and a deliberately broken 0.x fails.

## Where it goes

Into `beta/difftest`, Linux only like the rest of `beta/`, with the one
untagged `doc.go`. It drives two `conformance.Engine` values side by side,
using A1's interfaces in `beta/conformance/api.go`. P1 later runs it in CI on
every merge, and G2 and G4 run it against the Beta.

## To settle, and write down in this file

- **Operations and their mix:**
  - `Put` with random fields and awkward values, and vectors of the table's
    size, sometimes the wrong size;
  - `Get`, `Delete`, and `Scan` with prefix, after and limit;
  - `Link`, `Unlink`, `Neighbours`, and `Walk` with direction, type and
    depth;
  - `Nearest` with k and a filter;
  - `Drop`;
  - `Update` holding several operations, with random rollbacks from an
    error returned by the function;
  - plain SQL from a small fixed set, until A4's corpus exists.
- **Comparing results:**
  - Errors match by kind (`ErrNotFound`, `ErrInvalid` or another), and not
    by text.
  - Values must be equal, with floats compared by their bits.
  - Nearest compares through A1's `sameHits`, which allows for
    `DistanceBound`.
- **Comparing state after each sequence:** read through the `Handle` API:
  every table the sequence touched with `Scan`, and every key's links with
  `Neighbours`. 0.x's `Export` gives an exact view of a whole file too, but
  the conformance `DB` interface only gains it in G6.
- **Seeds and shrinking:** a sequence is a seed plus a length. When one
  fails, shrink it by halving and by dropping single operations. Write the
  smallest failing one to `beta/difftest/testdata/` as JSON, so it replays
  as a test from then on.
- **The broken 0.x:** an adapter around zerox that changes one behaviour,
  such as `Unlink` with a type removing every type, or `Nearest` dropping
  its last hit. The harness has to catch it within a set number of
  sequences.
- **How long it runs:** a few hundred sequences with `-short`, and a few
  thousand otherwise. An environment variable, read like A1's, sets more
  for R1's long runs.
