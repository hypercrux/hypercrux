# P3: Internal interfaces

Status: under way, in one round with P5. Planned at 2 hours. It needs P2, which is done.

## The contract

From BETA.md: internal interfaces: the file calls, so a fault layer can sit
under them; the change list; the snapshot compaction reads; the store's read
API; the value type; the operator iterator; error values. Done when it
compiles against stubs.

BETA.md adds that these interfaces change only through a small task that
updates every caller at once, so they're worth getting right here.

## What's there already

- **The format** (P2): `beta/FORMAT.md`, with six changes (create a table,
  put fields, delete a record, add and remove a link, drop a table) and six
  kinds of value (null, whole number, real, text, bytes, vector). Reals and
  vectors keep their bits.
- **What the file tasks need from the file calls,** from FORMAT.md and
  BETA.md:
  - data: read and write at an offset, append, sync, truncate, size, close;
  - locks: `flock` exclusive, tried without waiting or waited for up to 10
    seconds, plus the in-process mutex in front of it;
  - names: create under a `.new-` name, rename with and without
    `RENAME_NOREPLACE`, remove, directory sync, `stat` by path for the
    device, inode, link count and size, real paths with symbolic links
    resolved, and listing leftover `.new-` and `.compact` files.
  - T1's fault layer sits under the data calls, losing or tearing unsynced
    writes at a simulated power cut and failing any call at its nth use.
    T2's sits under the name calls.
- **0.x's public API,** which P4 copies as stubs and A1's adapter targets:
  `beta/conformance/api.go` has it as an interface (`Engine`, `Handle`,
  `DB`), with two sentinel errors, `ErrNotFound` and `ErrInvalid`.
  `beta/difftest` compares errors by kind (`difftest.Kind`).
- **The search loop** (A5): `beta/internal/vecmath`, with `Wide` for a query
  widened once.

## To settle, and write down in this file

Starting points, to weigh:

- **Where things live.** `beta/internal/` packages: the file calls (for
  example `fsys`), the codec in `format`, the in-memory copy (`store`),
  the operators and SQL later. And the path of the Beta's public package,
  which P4 fills: it has to sit beside 0.x's until R4.
- **The file calls:** an interface for an open file and one for the
  operations on names, small enough for T1 and T2 to wrap, with the real
  ones over `syscall` (no `golang.org/x/sys`; see P2.md on `renameat2`).
- **The change list:** the six changes as one struct with a kind, or one
  type each. It's what S3 emits as a transaction runs, F1 encodes, and a
  reader applies, so it should cost little to build and to apply.
- **The snapshot compaction reads:** tables in byte order of name, with
  their vector size and field list; each table's records in key order; then
  every link in order of from, type and to, which is FORMAT.md's order for
  a compacted part. It has to stream, without copying the database.
- **The store's read API:** what `Get`, `Scan`, `Neighbours`, `Walk` and
  `Nearest` need, including `Nearest`'s filter hook, and a table's fields
  and vector size.
- **The value type:** the six kinds, how 0.x's Go values map onto it (0.x's
  `Fields` gives back `string`, `int64`, `float64`, `[]byte` and a vector),
  and how a record's vector refers to its slot in the table's array (V1).
- **The operator iterator:** rows as values, pulled one at a time, with
  `Close` and an error at the end, serving scan, filter, project, sort, top
  k, limit and offset, and aggregates (Q4).
- **Error values:** 0.x's two, plus the Beta's own: damage, a file that
  isn't a Beta database, a 0.x database, a newer format version, the lock
  timing out, a handle stuck after a failed cut, and a call through the
  database inside `Update`. Each should map to one of difftest's kinds.
- **The stubs** that it compiles against, and a test that does nothing but
  build them.
