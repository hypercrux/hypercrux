# A1: Test suites from 0.x

Status: done, 7 October 2026.

## The contract

From BETA.md: 0.x's tests that don't depend on SQLite internals, in a Go
suite that runs on either engine through a thin adapter, and its command
tests run against any binary named in an environment variable. Done when
both pass against 0.1 unchanged.

## What was built

- `beta/conformance`: the `Engine`, `DB` and `Handle` interfaces and the
  types the tests use (`Fields`, `Vector`, `Direction`, `Link`, `Step`,
  `Hit`, `Record`, `Report`). `Run(t, e)` runs 25 tests as subtests and
  skips the ones the engine names in `Skip()`. `Tests()` lists their names.
  `Main(m, e)` goes in the adapter's `TestMain`, because the process tests
  start copies of the test binary.
- `beta/conformance/zerox`: the adapter for 0.x, and the test that runs the
  suite on it.
- `beta/conformance/cmdtest`: 0.x's `TestEveryCommand` in ten sections, run
  from outside against `HYPERCRUX_BIN`, or against 0.x's command built for
  the test when it's unset. `HYPERCRUX_CMD_SKIP` skips sections, and naming
  a section that doesn't exist fails the test.

Every file in `beta/` is Linux only except the one `doc.go` per package, so
on macOS and Windows the packages build empty. That was checked with
`GOOS=darwin` and `GOOS=windows`.

## The result

On 0.1, all 25 suite tests and all ten command sections pass.
`go test ./beta/...` takes about 55 seconds, most of it the 200 killed
writers, and `-short` takes about 8. The race detector finds nothing, and
`go vet ./...` is clean.

## What came over, and what stayed in 0.x

Whole, or with only engine-neutral changes:

- PutAndGetRoundTrip, PutKeepsFieldsItIsNotGiven, KeyAndFieldRules,
  MoreFieldTypes, GetAndDeleteMissing, Scan, LinksFollowTheirRecords, Walk,
  Vectors, NearestIsExact, WalkInSQL, OneStatementCrossesAllFour,
  VectorAsQueryArgument, UpdateIsAllOrNothing, GoroutinesShareADB,
  OneConnection and OpenNeedsAFile.
- KilledWritersNeverLeaveAMess and ProcessesShareAFile. 0.x's own kill test
  reads its link table after each kill. This one checks every record, the
  link count from `Check`, and every link the round's transactions could
  have changed, then every link at the end. It's quicker than 0.x's own
  version, 52 seconds against 68.

In part, leaving out what only SQLite has:

- OpenAndReopen, from TestOpenSetsUpTheFile, without the pragmas and
  `hc_meta`.
- NewFieldsShowAtOnce, from TestSchemaChangesShowAtOnce, without
  `ALTER TABLE`.
- RulesForLongKeysAndLinkTypes, without inserts into `hc_links`.
- TableNamesLikeHyperCruxsOwn, with the zero vector passed as an argument
  instead of `zeroblob()`.
- DropTable, the `Drop` part of TestDropAndAdoptAfterSchemaChanges.
- PlainSQLFollowsTheRules, without `hc_links`, `hc_keys` and the upsert.
  Blobs go in as arguments instead of blob literals.

Left in 0.x, because they test SQLite itself or 0.x's internals:

- TestOpenRefusesANewerFormat and TestOpenAddsTablesToAnExistingDatabase.
- TestPrefixEnd and TestCosine, which test internal functions. Distances are
  covered by NearestIsExact and the SQL tests.
- TestAdopt, TestCheckFindsProblems, TestReplaceOnAnotherUniqueColumn,
  TestRolledBackSchemaChange, TestNonFiniteVectorsStayOutOfSearch,
  TestStrictTables, TestKeysCompareExactly and
  TestMissingKeyColumnIsNotFound.
- The Python tests, and the benchmarks, which T5 mirrors.
- The command's TestOtherSQLiteFilesAreLeftAlone and TestCheckReportsProblems.

## Notes for later tasks

- P5 names the tests the Beta must pass:
  - WalkInSQL and UpdateIsAllOrNothing use the scalar form,
    `SELECT walk(...)` returning JSON, so P5 decides whether it's in the
    subset.
  - The command sections SQLTriggers and AdoptAndDrop are SQLite only; the
    Beta's run sets `HYPERCRUX_CMD_SKIP=SQLTriggers,AdoptAndDrop`.
  - The SQL section expects 0.x's error text, "keys in table docs are text
    that starts with docs:".
- KeyAndFieldRules keeps 0.x's rules exactly, so S1 must match them. That
  includes refusing keys for tables named `hc_*` and `sqlite_*`, and refusing
  the fields `key` and `rowid`.
- PutAndGetRoundTrip and MoreFieldTypes pin 0.x's value conversions, which
  S1 must match:
  - booleans become 1;
  - times become RFC 3339 text in UTC;
  - slices, maps and structs become JSON text;
  - small integer types become int64;
  - pointers are followed.
- `DistanceBound` is 1e-9. `sameHits` accepts either order within a run of
  distances closer than that, as BETA.md allows.
- The suite's `Vector` implements `driver.Valuer`, so it goes into SQL as a
  blob on both engines.
- CI now runs the suite too. On Linux, the kill test adds about a minute to
  `go test ./...`.
