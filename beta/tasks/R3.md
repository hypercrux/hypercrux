Status: done, 15 October 2026.

## The contract

From BETA.md: docs and site: `FORMAT.md` for the Beta, the README, notes on
moving from 0.x, posts. Done when a script checks the links and runs the
examples.

docs describe the code as they left it. It changed no Go code: no example
showed a fix was needed. No byte of the format changed, and the format is

- **[scripts/check-docs.py](../../scripts/check-docs.py),** new, which checks
  the links and runs the examples. With no argument,
  `python3 scripts/check-docs.py` checks the docs in this repository alone,
  and needs Go, and a C compiler to build 0.x's command. Given the path of a
  clone of the site, `python3 scripts/check-docs.py ../hypercrux.com`, it
  checks the posts too, and needs Hugo as well. The site's repository is
  private, so where the site can't be checked out, as in CI, it runs with no
  argument, and whoever publishes the posts runs it with the site's path
  before they go up.
  - **The docs it reads:** the six R3 wrote or touched, `README.md`,
    `beta/README.md`, `beta/FORMAT.md`, `beta/MOVING.md`, `beta/SQL.md` and
    this file, and with the site's path, the two posts.
  - **Links, three kinds:** to files, folders and headings' anchors in this
    repository, relative to the doc, with anchors worked out as GitHub works
    them out; to the site's own pages and images, looked up in the site as
    `hugo --quiet --noBuildLock -d DIR` builds it, DIR a new folder outside
    both repositories, with the anchors in the built page; and to GitHub's
    pages of this repository, `.../blob/main/PATH` and `.../tree/main/PATH`,
    by the file or folder they name, with the anchor. It finds inline links,
    reference definitions, autolinks, bare URLs, `href` and `src`, and a
    post's `featured_image`, outside code. Every other link it lists as left
    alone, since a check here can't reach other websites. Without the site,
    the links to its pages are left alone and listed too, under a line
    saying the site wasn't given, so its pages weren't looked up.
  - **Examples:** a fenced block runs when the line before it is a comment
    of its own: `<!-- run -->` runs a `sh` block with `sh -e`, the Beta's
    command first on PATH as `hypercrux`, or builds a `go` block, a whole
    program, against the Beta's package in this repository and runs it;
    `<!-- run 0.x -->` runs a `sh` block with 0.x's command, for the step
    that exports from 0.x; and `<!-- output -->` marks a block that has to
    match what the run before it printed, exactly. A doc's examples run in
    order in one new folder. The script builds the Beta's command with
    `CGO_ENABLED=0`, 0.x's with cgo when a doc needs it, and a module outside
    the repository whose `replace` points at it, as a program of a user's
    would import the package. Every other code block is left alone, and
    counted: fragments, the clone and `go get`, which need the network, the
    contributors' long test commands, and output that isn't compared.
  - **What it leaves behind:** nothing. Hugo writes no lock file, and its
    caches and output go to the temporary folder, which goes at the end.
    The script refuses a temporary folder inside either repository.
  - It prints each post's URL, the links it checked by kind, every link it
    left alone, and why, and the examples it ran, then each problem with its
    file and line, and exits with 1 when there's one. A wrong argument, or
    `-h`, gives its usage line.

## Decisions settled

**The format document stays beta/FORMAT.md.** That's the name BETA.md's plan
gives it, in the folder that holds the Beta, beside its README, SQL.md and
MOVING.md. It doesn't take FORMAT.md or EXPORT.md at the root, which are
0.x's and the shared export format's (A2.md), and every link and code comment
that names it, and `TestFormatVersionIsTheSpecs`, which reads its title,
carry on. Where the Beta's docs go if the Beta leaves `beta/` is a later
call.

**What FORMAT.md takes from BETA.md, and what stays there.** FORMAT.md has
every rule a writer keeps; BETA.md keeps the reasons and the measurements.
The rule for when HyperCrux compacts is in FORMAT.md, marked as HyperCrux's
own: the format doesn't need it, and a writer may compact whenever it holds
the lock, or never. The in-process mutex is described as HyperCrux's, with
the rule for any writer: one thread at a time through a file it opened
itself.

**The README is for users first.** What the Beta is, how to build and try
it, its costs and limits and the specs come first, then the differences from
0.x, then the contributors' sections. The differences stay in the README,
short, since a test's messages name that list, and MOVING.md gives each with
what to do.

**The notes on moving are beta/MOVING.md,** a plain name, beside the other
docs. Every difference comes as what changes and then "What to do".

**Examples are marked to run with a comment, and their output with
another.** An HTML comment on the line before a block is invisible on GitHub
and on the site, so a doc reads as before, and the script needs no guesswork
about which blocks are runnable. In the posts the comments reach the page's
source and nothing else: no summary or feed holds them. A doc's examples
share one folder, so a block can carry on from the one before, as a reader
would. The export step runs on 0.x's command, since the move it shows starts
there, and comparing the two exports byte for byte checks the shared format
in the docs as well.

**The script is Python's standard library.** `check-board.py` set the way,
and CI's runners have Python. Given the site, it builds Hugo's output
outside both repositories, with `--noBuildLock` and its caches outside too,
so the site keeps no build output.

**The site is optional.** The site's repository is private, so CI can't
check it out without a token, and the owner won't be asked to add one. With
no argument, the script checks the docs in this repository, and lists their
links to the site's pages among the ones it leaves alone, under a line
saying the site wasn't given; Hugo isn't needed then. With the site's path
it checks the posts and those links too. CI runs it with no argument, and
whoever publishes the posts runs it with the site's path before they go up.

**Figures.** Every figure in the posts and the README comes from the task
records or `test/results/beta-bench.txt`, whose last run, recorded at 22:03
UTC on 14 October 2026 after L1, gives the README's table. The count of 261
planted bugs is `beta/plants.txt`'s, 246 after C1, 5 from R2 part 2 and 10
from L1, as the records give them, and the chart's parts come from its
names. The run dates are each run's own.

**The posts' titles,** in the site's rules: the testing post leads with its
subject and gives two concrete facts, and the moving post gives its finding,
an export for the data and a new import path for Go. Both URLs come from
the titles, and the script prints them from the built site.
