## What's there already

- **The package's place** (P3): `beta/hypercrux`, package `hypercrux`,
  imported as `github.com/hypercrux/hypercrux/beta/hypercrux`, with only a
  `doc.go` so far.
- **0.x's exported API,** at the module root: `Open`, `DB` and `Tx` with
  their methods, `Update`, `Fields`, `Record`, `Vector` and its methods,
  `Link`, `Direction` and its three values, `Step`, `Hit`, `Report`, the
  constants (`Version`, `FormatVersion`, `MaxKeyLen`, `MaxDims`, `MaxK`,
  `MaxDepth`), `TableOf`, `ParseDirection`, `ParseVector`, `DecodeVector`,
  `Check`, `Export`, `Import`, and `ErrNotFound` and `ErrInvalid`. BETA.md's
  "The Go package and the command" leaves out `Adopt`, `ApplicationID` and
  `DriverName`, and adds `Compact()`.
- **P3's packages:** `errs` holds the error values the public package
  exports as the same values; `store`'s `Link`, `Direction`, `Step` and
  `Hit` match 0.x's field for field.
- **The conformance suite** (A1): `beta/conformance/api.go` is 0.x's API as
  an interface, and `beta/conformance/zerox` is 0.x's adapter. The Beta's
  goes beside it.

## To settle, and write down in this file

- **What can be real already:** constants, `TableOf`, `ParseDirection`,
  `ParseVector`, `DecodeVector` and `Vector`'s methods hold no state, so
  they may as well be 0.x's from the start, with tests.

  pass yet; skipped until G1, with a note saying so, is a starting point.
- **What the Beta exports beyond 0.x:** its own error values, from `errs`,
  so callers can tell damage and a lock timeout apart.
