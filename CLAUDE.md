# Notes for Claude

Releases are automated. To release, raise the version and push to `main`;
never ask the owner to publish one. [RELEASING.md](RELEASING.md) has the
whole procedure, the checks to run afterwards, and how to copy it to a new
project.

The Beta is built in rounds from the plan in [BETA.md](BETA.md). The task
board, [beta/tasks/README.md](beta/tasks/README.md), says where the work
stands and which round comes next, and a round starts only when the owner
says go.
